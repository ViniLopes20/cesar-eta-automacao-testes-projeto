Casos de Teste – XYZ Bank

Disciplina: Automação de Testes Ágeis  |  Ferramentas: Selenium WebDriver + Python

Aplicação sob teste: https://www.globalsqa.com/angularJs-protractor/BankingProject/#/login (AngularJS)

Instruções

  • O projeto deverá ser implementado em grupo.
  • Utilizar o padrão de projeto Page Objects.
  • Implementar no mínimo 3 testes por pessoa.
  • Implementar os testes usando Python + Selenium.
  • Serão avaliados:
    • Funcionamento correto dos testes;
    • Qualidade dos testes criados;
    • Qualidade do código implementado;
    • Boas práticas de programação.
  • Estarei disponível para dúvidas e suporte.

Dicas

  • Acesso sem senha: para entrar como gerente, clique em Bank Manager Login. Para entrar como cliente, clique em Customer Login, selecione o nome em Your Name e clique em Login. O botão Login só aparece depois da seleção do nome.
  • Os dados ficam no navegador (localStorage), não em um servidor. Um navegador novo começa sempre com os mesmos dados: 5 clientes (Hermoine Granger, Harry Potter, Ron Weasly, Albus Dumbledore e Neville Longbottom) e as contas 1001 a 1015. Por isso, abra um navegador novo para cada teste. Para voltar aos dados iniciais no mesmo navegador, execute driver.execute_script("window.localStorage.clear()") e depois driver.refresh().
  • Não recarregue a página no meio de um teste. Use os botões da aplicação (Home, Back, abas do gerente). Depois de um recarregamento, o saldo de uma conta pode voltar ao valor anterior.
  • Alertas JavaScript: Add Customer e Open Account mostram a resposta em um alert. Espere o alerta com EC.alert_is_present(), leia o texto com driver.switch_to.alert.text e feche com accept(). Enquanto o alerta está aberto, outros comandos geram UnexpectedAlertPresentException.
  • O número do cliente e o número da conta são gerados em sequência. Não fixe esses valores no código: leia o número no texto do alerta.
  • Os campos de seleção (Your Name, Customer, Currency e a conta do cliente) são <select> nativos. Você pode usar a classe Select do Selenium.
  • A aplicação usa AngularJS e atualiza a tela sem recarregar a página. Use esperas explícitas (WebDriverWait + expected_conditions), por exemplo, espere o texto do saldo mudar depois de um depósito. Evite time.sleep().
  • As URLs têm # (por exemplo, …/BankingProject/#/manager/addCust). Compare a URL completa, com o #.
  • Os títulos das colunas da lista de clientes são links com href="#". Depois de um clique para ordenar, a URL muda para …/BankingProject/#, mas a tela continua a mesma.
  • O extrato mostra as datas no fuso horário do navegador. Os campos de data do filtro são do tipo datetime-local, e o formato de digitação depende do idioma do navegador. Se send_keys não funcionar, preencha o campo com JavaScript e dispare os eventos input e change.
